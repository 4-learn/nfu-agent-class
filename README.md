# 從 Python 函式到 AI Agent 與 MCP（虎科大）

講義：https://hackmd.io/@yillkid/5u0eK8qWS-aWJw0PaAetwQ

## 下載

**[agent-class.zip](https://github.com/4-learn/nfu-agent-class/releases/latest/download/agent-class.zip)**：課程程式。解壓縮到 `C:\agent-class`，照講義第 1 節操作。

## 檔案

| 檔案 | 用在 |
| --- | --- |
| `equipment.py` | 三節共用的工具函式（器材借用） |
| `agent.py` | 第 1 節：自己寫的 Agent 迴圈 |
| `server.py`、`client.py` | 第 2 節：MCP server 與 client |
| `camera_client.py` | 第 2 節：連教室 Pi 5 攝影機 |
| `check.py` | 上課前檢查環境 |

`token.txt` 是你自己的 Token，**不要上傳**（已列入 `.gitignore`）。
